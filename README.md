# Victoria Love Franklin, PSM, CPT

Personal website: data science, GIS, government technology, applied AI research, and mentorship.

## Pages
- `index.html`: home (expertise, skills, projects, teaching, approach, affiliations, contact)
- `experience.html`: full experience, research, education, and recognition
- `work-with-me.html`: capability statement (use "Save as PDF" for a printable copy)

The site is plain HTML with fonts and images built in, so no build step is needed.

## Publishing (GitHub Pages)
Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
